# Architecture decision examples

This curated portfolio includes selected, sanitized decision records to show
how architectural trade-offs were documented. The complete decision history is
kept in the private development repository.

The public examples cover these broad topics:

- layered application architecture;
- schema-first validation;
- separation of deterministic calculations and LLM interpretation;
- workflow supervision and asynchronous execution;
- API and external-provider boundaries;
- container service boundaries and image optimization;
- CI quality checks and container security scanning.

The detailed production decisions, exact dependency choices, and
strategy-specific records are intentionally not indexed or published here.
The files in this directory are illustrative excerpts selected for technical
portfolio review.
